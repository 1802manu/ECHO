
# ECHO – AI Companion

ECHO is a voice-first AI companion project designed
to create personalised and emotionally adaptive
conversations.

## Project Vision

ECHO allows users to:
- Choose their own authorised voice profile.
- Connect voices shared by consenting individuals.
- Select an emotional communication preference.
- Experience adaptive conversational responses.
- Maintain a personal conversation history.

## Current Version

ECHO v0.1 – C Prototype

## Programming Language

C (C11)

## Current Features

- Welcome interface
- Voice profile selection
- Emotional preference selection
- Basic emotional context detection
- Linked-list conversation management
- Local conversation history

## Planned Features

- AI-powered conversations
- Custom authorised voice generation
- Speech recognition
- Expressive text-to-speech
- Real-time voice conversations
- User-approved long-term memory
- Flutter Android application

## How to Run

Compile:

gcc src/echo.c -o echo

Run on Windows:

echo.exe

Run on Linux/macOS:

./echo

## Privacy

Conversation history is stored locally.
Do not upload private conversations or
voice recordings to this repository.

## Disclaimer

ECHO is an AI companion prototype.
It does not currently clone voices or
provide professional mental health services.
